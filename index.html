Search syntax

Lexical

foo bar
Whitespace separates atoms; multiple atoms combine with implicit AND.
"foo bar"
Quote a value to keep whitespace inside one atom.
(a b)
Parentheses group atoms.

Booleans

a b · a AND b
Both match. AND/OR/NOT are case-insensitive keywords.
a OR b
At least one matches.
NOT a · -a
Negate the next atom. The - form must be at start of input or follow whitespace or (.

Operators

:
Substring for text fields; equality for numeric fields and mana costs; superset for color sets.
=
Equal for numeric fields, color sets, and mana costs; "all listed words present" for t=.
==
Strict equality. For t==, exactly the listed words and no others.
!=
Not equal.
< · <= · > · >=
Numeric ordering, or subset/superset relations for color sets and mana costs.

Name and text

foo
Bareword: case-insensitive substring of card name.
name:foo
Substring of card name (equivalent to bareword foo).
name="Foo Bar"
Exact card name.
t:creature · type:creature
Type line contains the substring creature.
t:"legendary creature"
Type line contains the literal substring (with the space).
t:spell
Has type instant or sorcery.
t:permanent
Does not have type instant or sorcery.
t:thing
Has type enchantment, artifact, or battle.
t=enchantment
Has the type word enchantment; with multiple words, all must be present.
t==enchantment
Has exactly the listed words as its complete type set (supertypes, types, subtypes).
t<="enchantment artifact"
Every type word on the card is among the listed words.
o:foo · oracle:foo · text:foo
Oracle text contains the substring foo. The character ~ in the value expands to the card's name.
o=foo · o==foo
Oracle text contains foo as a whole word (with word boundaries). Multi-word values stay literal: o="draw a card" requires the phrase with boundaries on each end.
o:/regex/
Case-insensitive regex on oracle text. No whitespace inside the slashes.
kw:flying · keyword:flying
Card carries the named keyword (matched against the parsed keyword list).
ft:foo · flavor:foo
Any printing's flavor text contains foo.

Regex shortcuts inside o:/.../: \spt any P/T like 1/1; \spp +N/+N; \smm -N/-N; \spm +N/-N; \smp -N/+N; \sbd any P/T modifier; \sm any {…} symbol; \sc any colored pip; \smr two consecutive colored pips; \smh a hybrid pip. Because \sc, \sm, \smh etc. are reserved, a literal \s followed by c, m, p, b, r, or h in the user's regex will be replaced.

Numeric fields

mv:N · cmc:N
Mana value equals N.
mv<N · mv<=N · mv>N · mv>=N · mv=N · mv!=N
Numeric comparison against mana value.
mv=odd · mv=even
Parity of the numeric value.
power:N · pow:N
Power equals N. Same operators as mv:.
toughness:N · tou:N
Toughness equals N.
loyalty:N · loy:N
Loyalty equals N.
defense:N · def:N
Battle starting defense equals N. Read from the Starting defense: N line in the oracle text.
pow=tou
Right-hand side may name another numeric field. Accepted on either side: mv/cmc, pow/power, tou/toughness, loy/loyalty, def/defense.

Mana cost (mana:)

mana:WW · mana=WW · mana==WW
Cost is exactly {W}{W} (multiset equality on pips, equal generic).
mana:1WW
Cost is exactly {1}{W}{W}. Digit runs sum to a single generic value.
mana>=Q
Cost is a multiset superset of Q (cost has at least everything in Q).
mana<=Q
Cost fits within Q.
mana>Q · mana<Q
Strict superset / strict subset of Q.
mana!=Q
Not multiset-equal to Q.
mana:U/G
Cost is exactly one hybrid pip {U/G}.
mana:c
Cost is exactly one colored pip.
mana:h
Cost is exactly one hybrid pip.
mana:m
Cost is exactly one colored pip. Multiple ms in one query bind to the same color.
mana:mm
Cost is exactly two colored pips of the same color.
mana:mn
Cost is exactly two colored pips of different colors.
mana:mno
Cost is exactly three colored pips of pairwise distinct colors.

Combine with >= for "contains at least these pips": mana>=mm matches any cost that includes two same-color pips, regardless of other generic or colored mana.

Pip letters: W U B R G exact colors; I silver (Voyager); V Vertex (Voyager); X; P Phyrexian; Vp prismatic.

Castability (castable:)

castable:wu · castable=wu
Card is castable from a pool of W and U mana (unlimited quantity, any combination).
castable:wuc
Pool letter c means colorless mana is also available, satisfying {C} pips.

Differs from mana<=: pool is a set of colors, not a multiset of pips. {W}{W} is castable from castable:w. Generic, X, Phyrexian {W/P}, and monohybrid {2/W} are always payable. Hybrids need either side in the pool. Vertex {V} is treated as always free. Prismatic {Vp} requires k distinct pool colors not already used by the spell's colored pips, where k is the number of {Vp} pips. Lands and no-cost spells never match.

Color and identity

c:w · color:w
Card colors include W. Letters are W U B R G I.
c:wu
Card colors include both W and U.
c=wu · c==wu
Card colors are exactly {W, U}.
c<=wu
Card colors are a subset of {W, U}.
c>=wu
Card colors are a superset of {W, U}.
c<wu · c>wu
Strict subset / strict superset.
c!=wu
Card colors are not exactly {W, U}.
c:c · c:colorless
Card has no colors.
c:m · c:multi · c:multicolor
Card has two or more colors.
c:N
Card has exactly N colors (N is a digit).
c:silver
Synonym for c:i.
id:wu · ci:wu · identity:wu
Color identity. Same value vocabulary and operators as c:.

Set and printing

e:CODE · set:CODE · edition:CODE
Some printing's set code or set name contains CODE. All operators behave the same; matches reprints regardless of which other sets the card also appears in.
e:A,B,C
Comma-separated list, OR-combined.
sets:A-B
Some printing's set falls in the chronological range from A to B, inclusive. Either bound may be omitted (sets:A-, sets:-B). Order of the two codes does not matter.
set>=CODE · set<=CODE · set>CODE · set<CODE
Some printing's set falls on the given side of CODE chronologically. E.g. set>=sol matches cards printed in Solastere or any later set.
cn:N · number:N · num:N
Collector number equals N. Numeric operators apply.
r:c · r:u · r:r · r:m · r:s
Rarity letter (common, uncommon, rare, mythic, special). Full names also accepted.
r<=u · r>=r
Rarity ordering: c < u < r < m < s. Matches if any printing satisfies the comparison.
a:foo · art:foo · artist:foo
Some printing's artist name contains foo.
layout:normal
Layout exactly equals the value. Known values include normal, split, transform, modal_dfc, saga, class, planar.

Legality

f:FORMAT · format:FORMAT · legal:FORMAT
Legal in the named format. Including this in a query overrides the format toggle.
banned:FORMAT
Banned in the named format.
restricted:FORMAT
Restricted in the named format.

is:

is:permanent
Does not have type instant or sorcery.
is:split · is:mdfc · is:transform · is:saga · is:class · is:planar
Layout is exactly that value.
is:reprint
Card has more than one printing in the corpus.
is:page
Card has a second-spell face (page-mechanic data present).
is:adventure · is:discharge
Card's page face has the named subtype.
is:vertex
Mana cost contains a Vertex pip (any pip whose contents include V).
is:hybrid
Mana cost contains any slash-pip.
is:prismatic
Mana cost contains the prismatic pip {Vp}.
is:common · is:uncommon · is:rare · is:mythic · is:special
Card's current rarity equals that value.
is:<tag>
Card carries the named user tag (or an alias resolving to it). Falls through when the value matches no built-in.

has:

has:flavor · has:flavour
Some printing has non-empty flavor text.
has:oracle · has:text
Card has non-empty oracle text.
has:power
Card has a numeric power value.
has:toughness
Card has a numeric toughness value.
has:loyalty
Card has a numeric loyalty value.
has:defense
Card has a numeric starting defense value (Battles).

manabase:

manabase:WUG
Card carries a tag of the form <colors>land whose colors are a subset of WUG, or utilityland, or goldland when the input has two or more colors.
manabase<=WUG
Equivalent to manabase:WUG.

sort:

sort:name
Order results ascending by canonical name.
sort:mv · sort:cmc
Order ascending by mana value.
sort:power · sort:pow
Order ascending by power.
sort:toughness · sort:tou
Order ascending by toughness.
sort:rarity
Order ascending by rarity rank.
sort:set
Order ascending by set code.
sort:color
Order ascending by color count.
-sort:<field>
Same field, descending.
